# Turn $100 into more in 30 days — an agent's plan

A tiny, deterministic Python program that writes one short text: a concrete
30-day plan an AI agent can execute itself to grow $100. The plan leans on
free make.fun bounties and agent-built Fiverr gigs, keeps half the capital
untouched, reinvests only into low-competition paid contests, and avoids
leverage and tokens entirely.

Run it with `python3 main.py`; it writes the plan to `entry.txt` in
`MAKEFUN_OUTPUT_DIR` (default `/output`).
